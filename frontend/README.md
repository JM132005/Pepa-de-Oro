# Pepa de Oro · Frontend (Angular)

Web pública (`src/app/publico/`) y sistema interno (`src/app/admin/`) en un solo proyecto Angular 21.

```powershell
npm install
npm start           # http://localhost:4200 (la API debe estar encendida)
npx ng build        # compilación de producción en dist/frontend/browser
```
