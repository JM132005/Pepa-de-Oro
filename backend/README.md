# Pepa de Oro · Backend (NestJS)

API REST en `http://localhost:3000/api` con 19 módulos, las reglas de negocio RN-01…RN-26 y la semilla de datos.

```powershell
npm install
Copy-Item .env.example .env
npm run seed        # 12 meses de datos ficticios
npm run start:dev   # modo desarrollo
npm test            # 126 pruebas
```
